# Campus Friction Management System

A comprehensive **Campus Friction Management System** developed using **Qt (C++)** and **SQLite**. The application provides dedicated dashboards and management modules for students, teachers, and administrators while demonstrating the practical implementation of **Object-Oriented Programming (OOP)** concepts.

---

## Features

### User Dashboards
- Student Dashboard
- Teacher Dashboard
- Admin Dashboard

### Student Management
- Student information management
- Student records

### Teacher Management
- Teacher information management
- Faculty records

### Attendance Management
- Record attendance
- View attendance details

### Result Management
- Manage student results
- Display academic performance

### Complaint Management
- Register complaints
- Track complaint status

### Notice Management
- Create and manage campus notices

### Placement Management
- Placement information management
- Student placement records

### Mess Management
- Mess-related information management

## Build Instructions

### Prerequisites

- Qt 6
- CMake
- C++17 Compiler
- Qt Creator

### Steps

1. Clone the repository

```bash
git clone https://github.com/anushkakashyap1903/CampusFriction.git
```

2. Open the project in Qt Creator.

3. Configure the CMake Kit.

4. Build and Run the project.
